# Biblioteczka filmów

Prosta aplikacja w React do wyświetlania i dodawania filmów do obejrzenia.

- stan `movies` (na początku pusta tablica)
- `useEffect` ustawia domyślne filmy: Shrek, Król Lew, Toy Story
- komponent `MovieList` wyświetla filmy przez `.map()`
- input + przycisk „Dodaj film” dodaje nowy tytuł na koniec listy

## Uruchomienie

```
npm install
npm run dev
```
